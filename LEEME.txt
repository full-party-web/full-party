Publicación gratuita con GitHub Pages:
1. Crea una cuenta en https://github.com/
2. Crea un repositorio público llamado full-party-web.
3. Sube index.html y la carpeta assets completa (con sus dos imágenes).
4. En Settings > Pages, selecciona Deploy from a branch, rama main y carpeta /(root).
5. Guarda. GitHub mostrará la dirección pública de tu web.

Nota: los eventos y enlaces de boletería se deben actualizar cuando estén confirmados.
